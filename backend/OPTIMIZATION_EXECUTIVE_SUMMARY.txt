┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 PROBLEMA IDENTIFICADO                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

Endpoint: POST /auth/register
Tiempo: 3-5 segundos ❌
Razón: Esperaba (await) envío de email ANTES de retornar


┌─────────────────────────────────────────────────────────────────────────────┐
│ 💡 CAUSA RAÍZ                                                               │
└─────────────────────────────────────────────────────────────────────────────┘

FLUJO ANTES:
  1. Usuario se registra
  2. Backend crea usuario en BD (50ms)
  3. Backend genera token (5ms)
  4. Backend ESPERA a que se envíe el email (3000ms) ← PROBLEMA
  5. Backend retorna respuesta
  6. Total: ~3050ms ❌

El email se enviaba SINCRONICAMENTE (bloqueaba toda la respuesta)


┌─────────────────────────────────────────────────────────────────────────────┐
│ ✅ SOLUCIÓN IMPLEMENTADA                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

Usar BackgroundTasks de FastAPI

FLUJO AHORA:
  1. Usuario se registra
  2. Backend crea usuario en BD (50ms)
  3. Backend genera token (5ms)
  4. Backend planifica envío de email en BACKGROUND
  5. Backend retorna respuesta INMEDIATAMENTE (total: ~50ms) ✅
  6. Email se envía en background (sin bloquear)
  7. Total: ~50ms (+ email en background)


┌─────────────────────────────────────────────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 CAMBIOS TÉCNICOS                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

ARCHIVO: app/routes/auth_route.py

ANTES:
  @router.post("/register")
  async def register(data: UsuarioCreate, db: Session):
      result = register_user(...)
      await send_verification_email(...)  ← BLOQUEA AQUÍ (3s)
      return response

AHORA:
  @router.post("/register")
  def register(data: UsuarioCreate, background_tasks: BackgroundTasks, db: Session):
      result = register_user(...)
      background_tasks.add_task(send_email_background, ...)  ← NO BLOQUEA
      return response  ← RETORNA INMEDIATAMENTE
