Paso 1: REGISTRARSE
────────────────────

    Abre Thunder Client
    Click: New Request
    Cambia a: POST
    URL: http://localhost:8000/auth/register
    
    Tab: Body
    Selecciona: JSON
    Copia esto:
    
    {
      "username": "mi_usuario",
      "correo_electronico": "mi@email.com",
      "password": "MiPassword123"
    }
    
    Click: Send
    
    ✓ Recibirás:
    {
      "message": "Usuario registrado exitosamente...",
      "user_id": 1,
      "verification_token": "eyJhbGc..."
    }
    
    👉 COPIA el "verification_token"


Paso 2: VER EL EMAIL (Mailpit)
───────────────────────────────

    Abre navegador:
    http://localhost:8025
    
    Verás el email con:
    - Asunto: "Verifica tu correo - AlecTours"

    - Token en la URL

┌─────────────────────────────────────────────────────────────────────────────┐
│                              OPCIÓN 3: cURL                                  │
└─────────────────────────────────────────────────────────────────────────────┘

Abre PowerShell y ejecuta estos comandos uno por uno:

# 1. REGISTRARSE
$registerData = @{
    username = "test_user"
    correo_electronico = "test@test.com"
    password = "TestPass123"
} | ConvertTo-Json

$registerResponse = Invoke-RestMethod -Uri "http://localhost:8000/auth/register" `
    -Method POST -Body $registerData -ContentType "application/json"

$token = $registerResponse.verification_token
Write-Host "✓ Token: $token"

# 2. VERIFICAR
$verifyResponse = Invoke-RestMethod -Uri "http://localhost:8000/auth/verify-email?token=$token" `
    -Method POST

Write-Host "✓ Verificado: $($verifyResponse.email)"

# 3. LOGIN
$loginData = @{
    username = "test_user"
    password = "TestPass123"
} | ConvertTo-Json

$loginResponse = Invoke-RestMethod -Uri "http://localhost:8000/auth/login" `
    -Method POST -Body $loginData -ContentType "application/json"

Write-Host "✓ Token de acceso: $($loginResponse.access_token.Substring(0,50))..."


┌─────────────────────────────────────────────────────────────────────────────┐
│                          ¿QUÉ DEBE PASAR?                                   │
└─────────────────────────────────────────────────────────────────────────────┘

✅ Cuando te registras:
   - Usuario guardado en BD con verificado=false
   - Email enviado automáticamente
   - Token generado (válido 24h)

❌ Cuando intentas login SIN verificar:
   - Error: "Por favor verifica tu email"
   - Status: 403 Forbidden

✅ Cuando verificas el email:
   - Email actualizado a verificado=true
   - Ya puedes iniciar sesión

✅ Cuando inicias sesión DESPUÉS de verificar:
   - Recibes access_token
   - Puedes acceder a recursos protegidos


┌─────────────────────────────────────────────────────────────────────────────┐
│                           SOLUCIONAR PROBLEMAS                               │
└─────────────────────────────────────────────────────────────────────────────┘

❌ "Error al conectar"
   → Verificar que el backend esté corriendo
   → Terminal: cd backend && python -m uvicorn app.main:app --reload

❌ "No veo el email"
   → Ir a http://localhost:8025 (Mailpit)
   → Refreshear la página
   → Verificar que Mailpit esté corriendo

❌ "Token inválido"
   → Copiar exactamente el token de la respuesta
   → Verificar que no tenga espacios
   → Probar dentro de 24h (si es más viejo expira)

❌ "Email ya registrado"
   → Usar diferente email
   → O registrarse con otro usuario

❌ "Username ya existe"
   → Usar diferente username
   → O añadir número: usuario_2, usuario_3, etc
